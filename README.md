# WhatsApp Chat

Веб-приложение для обмена текстовыми сообщениями через GREEN-API в интерфейсе, стилизованном под WhatsApp Web.

## Технологии

- React
- TypeScript
- Vite
- Tailwind CSS
- GREEN-API

## Запуск проекта

**Требования:** установленный [Node.js](https://nodejs.org/).

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Marsel33/Green-Api.git
   ```

2. Перейдите в папку клиента:

   ```bash
   cd Green-Api/client
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите приложение:

   ```bash
   npm run dev
   ```

5. Откройте адрес, указанный в терминале (обычно `http://localhost:5173`).

## Настройка GREEN-API

Для работы с сообщениями необходимы активный экземпляр GREEN-API и учётные данные:

- `idInstance`
- `apiTokenInstance`

Введите их в соответствующие поля приложения и подключитесь к аккаунту.

Возможность отправки и получения сообщений зависит от настроек экземпляра и ограничений выбранного тарифа GREEN-API.

## Возможности

- Подключение к GREEN-API.
- Создание чатов по номеру телефона.
- Отправка текстовых сообщений.
- Получение входящих сообщений.
- Отображение списка чатов и истории переписки.
